OPCIONES

Controles

Flechas / WASD: mover · Mouse: clic para caminar o interactuar · E: interactuar · I: inventario y equipo · O: opciones · ESC: cerrar ventanas

Mecánicas

Toca al enemigo para iniciar el combate ATB: cada personaje tiene su propio contador (la velocidad lo acelera). Cuando dice ¡LISTO! elige ATACAR, MAGIA, APOYO, OBJETOS o HUIR. Si el protagonista llega a 0 HP: GAME OVER. El HP es un contador rodante. Inventarios: 20 de utilidad y 20 de equipo.
